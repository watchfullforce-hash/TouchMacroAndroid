# Download the test APK

1. Open the repository Actions tab.
2. Select **Build Steam Card Farmer APK**.
3. Open the latest successful run.
4. Download the **Steam-Card-Farmer-APK** artifact.
5. Extract the ZIP and install app-debug.apk on Android. Allow installation from your browser or file manager if Android asks.

This is an installable UI prototype only, not a functioning Steam card farmer.
